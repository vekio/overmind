= Parser AST Showcase
:toc:
:sectnums:

This document exercises the syntax currently represented in the parser AST.
Its first paragraph spans two physical lines so the resulting node contains
normalized line breaks.

Inline content can be *strong*, _emphasized_, or `monospaced`.
The styles can be nested as `*_monospace bold italic_*`, while escaped marks
such as \*this pair\* remain literal text.

Unconstrained formatting works inside words such as **C**reate, fan__tastic__,
and re``format``ted. Visit https://example.com[the project site] or jump to
<<runtime-components,the runtime component table>>.
